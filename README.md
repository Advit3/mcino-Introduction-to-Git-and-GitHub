# Simple Interest Calculator

A small Bash command-line calculator for simple interest. It asks for the principal amount, annual interest rate, and time period in years, then calculates:

`simple interest = principal × rate × time / 100`

## Run

On Linux, macOS, or Windows with Git Bash:

```bash
bash simple-interest.sh
```

Enter positive numeric values when prompted. The result is shown in the same currency units as the principal.

## Example

```text
Principal amount: 1000
Annual interest rate (%): 5
Time period (years): 2
Simple interest: 100.00
Total amount: 1100.00
```
